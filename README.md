NETWORKWALKS – Week 2 Cybersecurity Internship

Reconnaissance, OSINT & Network Scanning

Project Overview

As part of my Week 2 Cybersecurity Internship at NETWORKWALKS, I focused on understanding the fundamentals of Reconnaissance, Open-Source Intelligence (OSINT), DNS Enumeration, Web Technology Identification, and Network Scanning.

During this week, I explored several cybersecurity tools using Kali Linux and learned how they are used during the information-gathering phase of security assessments.

Tools Explored & Learning Outcomes

1. theHarvester – OSINT Information Gathering

Learned how to gather publicly available information related to domains, including email addresses, subdomains, hosts, and other relevant information. Understood the importance of OSINT in passive reconnaissance.

2. WhatWeb – Web Technology Identification

Explored website technology fingerprinting and learned how to identify web servers, CMS platforms, frameworks, and other technologies used by websites.

3. WAFW00F – Web Application Firewall Detection

Learned about Web Application Firewalls (WAFs) and explored how WAFW00F helps identify and fingerprint firewall technologies protecting web applications.

4. WHOIS – Domain Information Lookup

Learned how to retrieve publicly available domain registration information, including registrar details, registration dates, and name server information.

5. NSLOOKUP – DNS Query and Lookup

Explored DNS fundamentals and practiced resolving domain names into IP addresses. Learned about DNS queries and different DNS record types.

6. DNSRecon – DNS Reconnaissance

Explored DNS reconnaissance and enumeration techniques, including DNS record analysis and subdomain discovery. Developed a better understanding of DNS infrastructure.

7. Maltego – Graphical OSINT & Relationship Mapping

Learned the fundamentals of graphical OSINT and explored how Maltego visualizes relationships between domains, IP addresses, organizations, and other digital entities.

8. Zenmap – Network Scanning & Visualization

Explored network discovery and scanning through Zenmap's graphical interface. Learned how to interpret scan results and understand discovered network services.

Key Skills & Knowledge Gained

Throughout this week, I strengthened my understanding of:

- Reconnaissance methodologies

- Web Application Firewall detection
